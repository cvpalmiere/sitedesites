## 📖 Sobre o projeto

Site interativo de estudos para a disciplina de **Design de Interfaces**.  
O usuário escolhe um "livro" na estante virtual e o conteúdo correspondente aparece na tela — cobrindo os 5 principais tópicos da matéria.

> 💡 **Como usar:** clique em um dos livros da estante para ler o conteúdo.
